# Auto-pick chooses by personal Queue, then a position-aware Sleeper fallback, and always fills required starter slots

When a Manager's pick timer expires — and the Commissioner has left expiry-triggered Auto-pick enabled for the Draft (a per-Draft toggle, default on) — or when a Team is in Auto-draft mode, Auto-pick selects a Player in a fixed order of preference: (1) the highest-ranked available Player in that Manager's personal **Queue**; (2) if the Queue is empty or exhausted, the best available Player by **Sleeper's built-in rank** (`search_rank`), filtered to positions the Team can still legally roster; and (3) when the Team's remaining open slots can only be satisfied by specific positions, it prioritises those unfilled **required starter slots** first, so every auto-drafted Team finishes with a legal Week-1 Lineup.

**Why:** the alternative — dumb best-available by a single global ranking — produces bad, impersonal picks and, worse, can leave an absent kid's Team with no kicker or defense (an illegal, unstartable Lineup) because a generic Bench masks the shortage until the final rounds. The personal Queue makes Auto-pick reflect the Manager's actual intent and is the main quality lever; the required-slot guarantee protects the kid who leaves the room. Sleeper's rank was chosen as the fallback because it is already ingested in the player-sync pipeline and is "good enough" for a kids' league, avoiding the chore of a Commissioner-curated global ranking.

**Consequences:** this shapes both schema and UI. The `players` table gains a `search_rank` column and the importer must populate it from Sleeper (a Wave-1 gap being absorbed in Wave 2). The Draft needs a per-Manager Queue (storage, drag-to-rank UI, live editing). Auto-pick logic must know each Team's roster shape and remaining slots to apply the position filter and required-slot guarantee. A Manager's Queue is followed as-is even if it is "irrational" (e.g. three QBs) — position-awareness applies only to the global fallback, not to explicit Queue choices. Whether an expired timer *triggers* Auto-pick at all is a Commissioner setting: with it off, an expired timer leaves the Team on the clock indefinitely until a real pick or a Commissioner action, so the Auto-pick logic is still always built (Auto-draft mode and Commissioner-initiated auto-draft use it regardless) — the toggle governs only the expiry trigger.
