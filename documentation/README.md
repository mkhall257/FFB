# FFB Documentation

Human-facing guides and runbooks for operating the FFB league site. These are
distinct from `docs/` (agent/architecture material: ADRs, domain notes) — this
folder is for how-to documentation you'd hand to a person.

| Document | What it covers |
|----------|----------------|
| [Running a mock season](running-a-mock-season.md) | Dry-run a full season (draft → weeks → playoffs) against the real data feeds, locally or on the server, before a live draft. |

Each guide is written in Markdown (the source of truth) and may have a rendered
`.pdf` alongside it for sharing or printing.
