# Dragon Fantasy Football — Production Graphics Library, Batch 1

This batch contains:
- 5 hero images
- 5 background images

These assets were extracted from the approved Batch 1 concept board and upscaled for web prototyping.
They are suitable for layout integration and UI development. For final production launch, review them at
full browser size and replace any asset that needs a cleaner high-resolution master.

No official Carroll ISD logos or trademarks are intentionally included as reusable brand assets.

## Suggested usage
- `heroes/`: desktop hero banners, recap headers, matchup/awards promotional sections.
- `backgrounds/`: page section backgrounds, draft/commissioner ambient backgrounds, texture zones.
